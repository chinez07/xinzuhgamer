Configurar Pix (Mercado Pago)

O token do MP nunca vai no site público. Ele fica no Cloudflare Worker.

1. Access Token

  1. Abra Painel de Desenvolvedores MP
  2. Crie uma aplicação (ou use uma existente)
  3. Credenciais de teste primeiro (depois produção)
  4. Copie o Access Token (começa com APP_USR- ou TEST-)

2. Cloudflare Worker

  1. Cloudflare → Workers & Pages → Create Worker
  2. Nome: bloxzuh-pix
  3. Cole o código de workers/mp-pix.js
  4. Deploy
  5. Settings → Variables and Secrets → Add Secret:
    Nome: MP_ACCESS_TOKEN
    Valor: seu Access Token
  6. Copie a URL, tipo:
    https://bloxzuh-pix.xxxx.workers.dev

3. Site

  1. Edite js/mp-config.js:
window.MP_WORKER_URL = 'https://bloxzuh-pix.xxxx.workers.dev';
  1. Commit no GitHub → Cloudflare Pages atualiza

4. Verificar a integração

Esta é uma referência técnica para a administração. Gerar um Pix não confirma pagamento nem libera o chat.
  1. Execute os testes automatizados de pedidos e pagamentos no repositório antes de publicar alterações.
  2. Na produção, o servidor confirma o pagamento diretamente no Mercado Pago e confere pedido, conta, valor e ambiente.
  3. Pagamentos de teste não liberam compras reais. Não marque pedidos como pagos manualmente no Firebase.
  4. O chat só é liberado após a confirmação verificada. Não há prazo fixo de três segundos.
