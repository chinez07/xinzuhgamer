Configurar Pix (Mercado Pago)

O token do MP nunca vai no site público. Ele fica no Cloudflare Worker.

1. Access Token

  1. Abra Painel de Desenvolvedores MP
  2. Crie uma aplicação (ou use uma existente)
  3. Credenciais de teste primeiro (depois produção)
  4. Copie o Access Token (começa com APP_USR- ou TEST-)

2. Cloudflare Worker

  1. Cloudflare → Workers & Pages → Create Worker
  2. Nome: bloxzuh-pix
  3. Cole o código de workers/mp-pix.js
  4. Deploy
  5. Settings → Variables and Secrets → Add Secret:
    Nome: MP_ACCESS_TOKEN
    Valor: seu Access Token
  6. Copie a URL, tipo:
    https://bloxzuh-pix.xxxx.workers.dev

3. Site

  1. Edite js/mp-config.js:
window.MP_WORKER_URL = 'https://bloxzuh-pix.xxxx.workers.dev';
  1. Commit no GitHub → Cloudflare Pages atualiza

4. Testar

  1. COMPRAR → checkout → Pix com nome e CPF válidos
  2. QR real do Mercado Pago aparece
  3. Pague com conta de teste do MP (ou produção depois)
  4. Em ~3s o site detecta e libera o chat
Contas de teste MP: no painel de desenvolvedores há compradores de teste para Pix sandbox.
